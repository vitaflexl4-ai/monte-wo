The Epley estimate+
Estimated 1RM = load × (1 + repetitions / 30)

For a single repetition, this tool uses the entered load directly instead of adding the formula’s extra 3.3%. It accepts 1–30 whole repetitions. More reps and sets far from failure can make the estimate less reliable.

The percentage table is arithmetic, not a workout prescription. No estimate guarantees you can safely lift the displayed weight. A calculated 1RM is separate from Monte Wo’s MONTE WO Strength Index™.
